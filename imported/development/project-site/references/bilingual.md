# 中英文站点

## 路由与切换

已有站点以当前 URL 为准。新站静态默认如下，可按现有托管的 base path 调整：

| 页面 | 简体中文 | English |
| --- | --- | --- |
| 项目介绍 | `/` | `/en/` |
| 使用手册 | `/guide/` | `/en/guide/` |

在静态构建阶段输出每个译页。URL 决定语言，用户可直达、复制、刷新和用浏览器返回。中文站点默认根路径，不强制按浏览器语言重定向。每页用可键盘访问的 `中文` / `English` 真链接切换，标记当前语言。切换链接在手机上也常驻。关闭 JS 时，两种语言和基本导航仍可用。

用页面标识配对译页，章节用稳定 ID。首页和手册各自切换到另一语言的对应页面，当前锚点存在于译页时一起保留。改造旧站时保留旧 ID 或提供兼容映射。用户明确接受分期翻译时，把缺失译页标记为未翻译，并给出可见的原语言链接。仅为真实存在的对应译文声明交替语言链接。

## 内容与元数据

- 渲染正确的 `<html lang="zh-CN">` 和 `<html lang="en">`。标题、摘要、主视觉说明、导航、目录、搜索、复制结果、错误、可访问名称和替代文本一并本地化。搜索索引和结果跟随当前语种。
- 共享布局、样式和事实标识。短文案可集中管理，长正文复用项目已经存在的双语文档。缺少译稿时从事实源翻译到独立文件并保留术语、命令、文件路径、数值、版本、前置条件和限制。源文档变更时同步核对译稿。
- 发布地址已确认时，设置各页独立的 canonical，添加双向的 `hreflang="zh-CN"` / `hreflang="en"`，可用 `x-default` 指向默认语种。使用实际生产 URL，预览产物无需占位域名。
- 有语言偏好记忆时，以用户访问的明确路由为准。框架默认语言开关与缺译回退要在实际构建中检查。

## 验收

检查四个基础路由及更多成对页面，覆盖中英文导航、页面与锚点切换、深链接刷新、同语种文档链接、返回和键盘操作。验证译文与事实源一致，包括操作后的动态文案。无 JS 环境检查静态正文、切换和文档入口。发布时重验生产路径、两个语言版本及其准确的元数据。
